# Privacy

The current interface shell does not access the camera. The completed
application must request camera access only after an explicit user action.
Frames must remain on the device: no uploads, analytics or hidden recording.
Stopping the camera must release all media tracks. Sample mode must work
without permission. Snapshots, if introduced, require separate explicit consent.

Hardware diagnostics can contain device identifiers. Keep raw output local,
review redacted facts and publish only what is needed to explain compatibility.
