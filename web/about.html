Beyond the looking glass

A second life
for forgotten machines.

SpecterMirror is an open-source experiment in making older computers useful, expressive and a little unsettling.

Built around Rust, a CPU-only Linux path and local browser processing, it aims to make interactive installations possible without modern graphics hardware. Kiro specifications describe the application components and their verification requirements.
